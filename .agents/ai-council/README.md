# دليل تشغيل مجلس الذكاء الاصطناعي الأعلى (AI Council Operating Manual)
## نظام Multi-Agent متكامل للتشريح الهندسي والتحكيم الاستراتيجي

---

### نظرة عامة (Overview)
نظام **`ai-council`** هو مجلس استشاري وتنفيذي متعدد الوكلاء (Multi-Agent System) مصمم لإخضاع المشاريع البرمجية والنظم التقنية لأعلى درجات الفحص والتمحيص دون أي مجاملات أو أوهام. يتحدث أعضاء المجلس باللغة المصرية الاحترافية المعتمدة في مجتمع التكنولوجيا وريادة الأعمال في مصر والشرق الأوسط، مستندين إلى دساتير فحص صارمة تتجاوز **35 قاعدة تفصيلية لكل تخصص**.

---

### ملفات كل مساعد (The 4 Core Files per Agent):
داخل كل مجلد من مجلدات المساعدين الستة، توجد 4 ملفات تشغيلية متكاملة:
1. **`persona.md`:** البروفايل النفسي والمهني، النماذج العقلية، قاموس المصطلحات، اللزمات الأيقونية، والنبرة التعبيرية.
2. **`system-prompt.md`:** أمر التشغيل النهائي (System Prompt) المكتوب بهندسة أوامر متقدمة، متضمناً قيود منع النفاق وبروتوكول الاشتباك مع باقي الأعضاء بالاسم.
3. **`checklist-and-rules.md`:** الدستور الفني؛ أكثر من 35 نقطة فحص تفصيلية وصارمة خاصة بتخصص المساعد لاختبار المشاريع.
4. **`agent-runner.js`:** كود Node.js كامل يقرأ ملفات المساعد، يجهز التعليمات البرمجية، ويدعم العمل مع نماذج الـ LLM الخارجية أو محرك المحاكاة التحليلي عالي الدقة المدمج.

### طريقة تشغيل المجلس (How to Run the Council):

#### 1. التشغيل المباشر من خلال Node.js:
يمكنك الدخول إلى مجلد `ai-council` وتشغيل المجلس فوراً دون الحاجة لتثبيت أي مكتبات خارجية:

```bash
cd ai-council
node 00-orchestrator/debate-engine.js
```

#### 2. استخدام أوامر الـ NPM المدمجة:
```bash
# تشغيل جلسة نقاش كاملة من جولتين
npm run council

# تشغيل جلسة موسعة من 3 جولات
npm run council:3rounds

# تشغيل مساعد فردي لاختباره بمفرده (مثال: الشكاك الشرس)
npm run agent:critic

# أو اختبار صائد الثغرات
npm run agent:hacker
```

#### 3. خيارات الـ CLI المتقدمة:
```bash
node 00-orchestrator/debate-engine.js --rounds=3 --topic="بناء منصة مدفوعات إلكترونية ومحفظة رقمية للمستهلكين في مصر"
```

### كيفية ربط مفاتيح الـ LLM الخارجية (اختياري):
المجلس يعمل فورياً **Out-of-the-box** بنظام المحاكاة الذكي دون الحاجة لأي مفاتيح. إذا أردت ربطه بنماذج OpenAI أو Claude أو Gemini، انسخ ملف `.env.example` إلى `.env` وضع مفتاحك:

```env
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxx
COUNCIL_MODEL=gpt-4o
```
ثم شغل المجلس وسيتولى استدعاء النماذج الخارجية مباشرة.
